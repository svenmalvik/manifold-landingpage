Built for parallel agents

Run multiple AI coding agents on the same codebase without stepping on each other's work.

Isolated branches

Each agent gets a dedicated git worktree branched from main. No merge conflicts between agents. Manifold creates, manages, and cleans them up.

Every project, one window

Register all your repositories. Switch between them instantly. Run agents on your backend and frontend simultaneously from the same app.

Any agent, side by side

Claude Code, Codex, Gemini CLI, Copilot, Ollama — run them all in parallel on the same repo. Real PTY terminals, real output, no wrappers.
